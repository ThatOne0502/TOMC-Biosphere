# TOMC-Biosphere

> 📘 **数据驱动教程** — [data-driven.zh-CN.md](data-driven.zh-CN.md)

**TOMC-Biosphere** 是一个面向 **Fabric**（Minecraft **1.21.11**）的数据驱动生态模组。它用三大相互交织的系统为你的世界注入生机——**食物链关系**、**进食互动**与**随机刻环境演替**——全部由纯 JSON 文件驱动，你可以用数据包随意扩展，无需编写任何 Java 代码。

## 特性

### 🍖 食物链关系

生物构成真实的食物网。捕食者猎杀，猎物逃跑——包括那些本不战斗的被动生物：

- **鸡**猎杀蠹虫 · **犰狳**猎杀蜘蛛 · **豹猫**猎杀苦力怕。
- **海豚**猎杀鱿鱼 · **北极熊**猎鱼。
- **僵尸**猎牲畜 · **骷髅**猎猎物 · **幻翼**、**潜影贝**与**恼鬼**各得猎物。
- 猎物逃离天敌：悦灵逃恼鬼、牲畜逃亡灵、鱼逃北极熊、村民逃骷髅、苦力怕逃豹猫。

被动生物获得全新的近战 AI，其伤害、追击速度与冷却均可配置。

### 🥕 进食互动

动物啃食周围的世界，各自带绵羊式低头动画：

- **牛**吃草、吃菌丝，并按可配置概率转化为**哞菇**。
- **骆驼**寻路到仙人掌并从根部进食。
- **猪**寻找成熟的作物、西瓜与南瓜。
- **哞菇**啃食蘑菇，并把菌丝变回泥土。
- **马、驴、骡**像绵羊一样吃草。

### 🌱 随机刻演替

方块通过随机刻演化——正是原版草蔓延所用的机制：

- 花朵凋谢，掉落对应的染料。
- 草生长；枯草演替出新植株；枯叶堆把草方块变成灰化土。
- 露天末地石长出紫颂花；紫颂植株枯萎。
- 绯红/扭曲菌岩蔓延植被；下界植物凋零。
- 每条规则都可携带**谓词**（`biomes`、`can_see_sky`、`block` 等），让变化只发生在你期望的地方。

### 🐚 自然刷新

扩展生物刷新的位置：**幻翼**游荡于末地小岛，**末影螨**爬行于末地中部。

## 设计思路

上述每一种行为都是 `data/biosphere/` 下的一条 **JSON 规则**。模组附带一套合理默认值，并从数据包资源管理器读取，因此你只需往数据包里丢一个文件即可增删改任意行为——无需代码、无需重新构建。三种规则格式（演替、关系、刷新）详见下方链接的教程。

## 环境要求

- Minecraft **1.21.11**
- Fabric Loader **0.19.5+**
- [Fabric API](https://modrinth.com/mod/fabric-api)
- [Cloth Config](https://modrinth.com/mod/cloth-config)（配置界面）
- [Mod Menu](https://modrinth.com/mod/modmenu)（可选——用于打开配置界面）

## 配置

服务器权威配置可在游戏内通过 **Mod Menu → TOMC-Biosphere** 编辑：

- **功能模块** —— 开关食物链 AI、环境演替、生物刷新数据包，并设置牛→哞菇转化概率。
- **被动生物攻击** —— 近战伤害、追击速度、攻击冷却与逃跑速度。
- **creefern 联动** —— 与 Creefern 模组的兼容开关。

已加载数据的改动在世界重载后生效。
